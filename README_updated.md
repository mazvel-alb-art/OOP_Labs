# Лабораторная работа 1 — загрузка, анализ и предобработка данных

Консольное приложение на C++20 для загрузки табличного датасета, определения типов признаков, анализа пропущенных значений, расчёта статистики и подготовки данных к дальнейшему использованию в задачах машинного обучения.

## Датасет

Используется набор **Credit Approval (crx)** из UCI Machine Learning Repository.

- **Источник:** https://archive.ics.uci.edu/dataset/27/credit+approval
- **Файл:** `data/crx.csv`
- **Количество объектов:** 690
- **Количество исходных признаков:** 16
- **Целевой признак:** `A16` (`+` / `-`)
- **Пропущенные значения:** `?`
- **Разделитель:** `,`
- **Заголовок:** первая строка файла

Датасет содержит как числовые, так и категориальные признаки и подходит для последующих задач классификации.

## Архитектура

Исходный CSV после загрузки не представляется обычной числовой матрицей. Данные хранятся **по столбцам**, поскольку столбцы могут иметь разные типы.

Основные сущности:

- `Dataset` — хранит исходный датасет и выполняет загрузку, анализ и предобработку;
- `NumericColumn` — числовой столбец;
- `CategoricalColumn` — категориальный столбец;
- `Column` — `std::variant<NumericColumn, CategoricalColumn>`;
- `NumericFeatureInfo` — статистика числового признака;
- `CategoricalFeatureInfo` — статистика категориального признака;
- `FeatureInfo` — `std::variant` двух видов информации о признаке;
- `DatasetInfo` — информация обо всех признаках;
- `Matrix` — итоговая плотная числовая матрица после предобработки.

Упрощённо поток данных выглядит так:

```text
CSV
 |
 v
Dataset
 |
 +-- columns
 |    |
 |    +-- NumericColumn
 |    |
 |    +-- CategoricalColumn
 |
 +-- analyze()
 |       |
 |       v
 |   DatasetInfo
 |
 +-- statistics()
 |
 +-- preprocess()
         |
         +-- заполнение пропусков
         +-- min-max масштабирование
         +-- one-hot кодирование
         |
         v
      Matrix
```

### Хранение столбцов

Числовые значения:

```cpp
std::vector<std::optional<double>>
```

Категориальные значения:

```cpp
std::vector<std::optional<std::string>>
```

Тип столбца хранится через:

```cpp
using Column = std::variant<NumericColumn, CategoricalColumn>;
```

Порядок признаков дополнительно хранится в `column_order`, поскольку `std::unordered_map` сам по себе порядок элементов не гарантирует.

### Пропущенные значения

В исходном файле пропуск обозначается символом `?`.

После загрузки:

```text
?
```

представляется как:

```cpp
std::nullopt
```

Таким образом, пропуск не заменяется специальным числом вроде `-9999`.

## Определение типа признака

Тип каждого столбца определяется автоматически.

Алгоритм:

1. Читаются все непустые значения столбца.
2. Для каждого значения выполняется попытка преобразования через `std::stod`.
3. Если все непустые значения успешно разбираются как числа, столбец считается числовым.
4. Если хотя бы одно значение не разбирается как число, столбец считается категориальным.
5. Значения `?` при определении типа игнорируются.

Порогов по количеству уникальных значений не используется.

Такое правило подходит выбранному датасету: его числовые признаки действительно содержат числа, а категориальные — строковые значения.

---

## Проверка CSV

При загрузке выполняется проверка согласованности файла.

Проверяется, что:

- строки содержат одинаковое количество полей;
- количество столбцов соответствует заголовку;
- при нарушении выводится сообщение с номером проблемной строки.

Количество строк и столбцов определяется из самого файла, поэтому изменение количества объектов или порядка столбцов не требует изменения программы.

---

## Анализ датасета

После загрузки программа формирует сводку:

- количество объектов;
- количество признаков;
- название каждого признака;
- тип каждого признака;
- количество пропусков;
- доля пропущенных значений;
- общее количество пропусков.

Статистика хранится отдельно от исходных данных в `DatasetInfo` и не должна изменять содержимое датасета.

### Числовые признаки

Для числового признака рассчитываются:

- количество пропусков;
- минимум;
- максимум;
- среднее;
- дисперсия;
- `q05`;
- `q25`;
- `q50` — медиана;
- `q75`;
- `q95`;
- частотная гистограмма.

При расчётах пропущенные значения не участвуют.

Квантили вычисляются после получения и сортировки непустых значений. Для промежуточной позиции используется линейная интерполяция.

### Категориальные признаки

Для категориального признака рассчитываются:

- количество пропусков;
- список встречающихся категорий;
- частота каждой категории;
- текстовая частотная гистограмма.

## Предобработка

Метод `Dataset::preprocess()` строит отдельную плотную числовую матрицу. Исходные столбцы при этом не заменяются полученными значениями.

Предобработка состоит из трёх этапов.

### 1. Заполнение пропусков

Для числовых признаков используется **медиана**.

Медиана вычисляется по исходным непустым значениям до заполнения пропусков.

Для категориальных признаков используется дополнительная категория:

```text
__MISSING__
```

Она добавляется к списку категорий, если в столбце есть пропуски.

### 2. Min-max масштабирование

Числовые признаки масштабируются по формуле:

```text
x' = (x - min) / (max - min)
```

В результате значения переводятся в диапазон `[0, 1]`.

Минимум и максимум определяются по исходным непустым значениям.

### 3. One-hot кодирование

Категориальные признаки преобразуются в набор бинарных столбцов.

Например:

```text
A4 = u, y, l
```

превращается в:

```text
A4_u
A4_y
A4_l
```

Для каждого объекта в соответствующем столбце записывается `1`, если объект относится к категории, и `0` в противном случае.

При наличии пропусков появляется дополнительный столбец:

```text
A4___MISSING__
```

Имена столбцов итоговой матрицы сохраняются в `Matrix::matrix_column_names`.

Порядок категорий соответствует порядку их первого появления в исходных данных.

---

## Класс `Matrix`

После предобработки результат хранится в классе `Matrix`.

В текущей реализации матрица представлена как:

```cpp
std::vector<std::vector<double>>
```

То есть внешний `vector` содержит строки объектов, а внутренний `vector` — значения признаков конкретного объекта.

Дополнительно хранится:

```cpp
std::vector<std::string> matrix_column_names;
```

Он содержит названия столбцов полученной матрицы.

Например:

```text
0 -> A2
1 -> A3
2 -> A1_b
3 -> A1_a
...
```

Это позволяет связать столбец числовой матрицы с исходным признаком или категорией.

## Бинарное сохранение

Для `Matrix` реализованы:

```cpp
void save_binary(const std::string& file_name);
void load_binary(const std::string& file_name);
```

Формат файла:

```text
rows
columns
matrix data
```

Сначала записываются:

1. количество строк типа `std::size_t`;
2. количество столбцов типа `std::size_t`;
3. значения матрицы типа `double`.

Значения записываются построчно: сначала все элементы первой строки, затем второй и т.д.

Упрощённо структура файла выглядит так:

```text
+-----------------------+
| rows                  |
+-----------------------+
| columns               |
+-----------------------+
| row 0: double...      |
+-----------------------+
| row 1: double...      |
+-----------------------+
| ...                   |
+-----------------------+
```

При загрузке сначала считываются размеры матрицы, затем под них выделяется память и после этого считываются значения.

Названия столбцов в текущем бинарном формате не сохраняются.

### Ограничения бинарного формата

Формат предназначен для учебной задачи и не является переносимым универсальным форматом.

Причины:

- размер `std::size_t` зависит от платформы;
- порядок байтов не фиксируется;
- размер и представление `double` предполагаются одинаковыми;
- отсутствует версия формата;
- отсутствует контрольная сумма или другой механизм проверки целостности.

## Почему вычислительные функции используют `NumericColumn`

В условии рекомендуется использовать `std::span<const double>` для вычислительных функций.

В текущей реализации статистические функции работают непосредственно с `NumericColumn*`.

Причина — числовой столбец содержит:

```cpp
std::optional<double>
```

и статистика должна уметь пропускать `std::nullopt`.

Использование обычного:

```cpp
std::span<const double>
```

потребовало бы предварительно собрать все непустые значения в отдельный массив либо использовать другое представление для `optional`.

Поэтому в текущем варианте функции получают `NumericColumn`, обходят его и пропускают отсутствующие значения без дополнительного копирования данных.

## Работа программы

Основной сценарий:

1. Загружается `data/crx.csv`.
2. Выполняется проверка согласованности CSV.
3. Определяются типы столбцов.
4. Печатается сводная информация по датасету.
5. Пользователь выбирает номер признака.
6. Для выбранного признака выводится статистика.
7. Ввод `-1` завершает цикл анализа.
8. Программа спрашивает, нужно ли сохранить предобработанный датасет.
9. При ответе `yes` выполняется предобработка.
10. Полученная матрица сохраняется в `data/binary.bin`.
11. Выводится размер исходного CSV и бинарного файла.

## Обработка некорректного ввода

Программа не должна завершаться при обычной ошибке пользовательского ввода.

При вводе вместо номера признака:

- очищается состояние `std::cin`;
- игнорируется некорректная строка;
- выводится сообщение об ошибке;
- цикл продолжается.

Номер признака проверяется на допустимый диапазон.
