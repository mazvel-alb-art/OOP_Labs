Detailed Description

Решающий пень — дерево решений глубины 1.

Модель выбирает один признак j и один порог t. Объекты с X[i][j] <= t попадают в левую часть, остальные — в правую. В каждой части предсказывается константа:

  • для регрессии — среднее отклика в части;
  • для классификации — самый частый класс.

Обучение — перебор всех (j, t) с инкрементальным обновлением агрегатов за O(1). Сложность O(d * n log n), память O(n).
