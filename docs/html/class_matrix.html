Detailed Description

Плотная числовая матрица с плоским хранением данных (RowMajor).

Данные лежат в одном непрерывном std::vector<double>. Строка i — это подотрезок [i*cols_, (i+1)*cols_). Это позволяет возвращать std::span на строку без копирования.
