Detailed Description

Табличный датасет: столбцы, статистика, предобработка.

Хранит столбцы двух типов (числовые и категориальные) в std::variant. Пропуски — std::nullopt. По запросу анализирует (analyze) и преобразует данные в плотную числовую матрицу (preprocess).

Matrix & Dataset::preprocess ( )

Предобработка датасета.

Returns
Ссылка на матрицу признаков.

Заполняет пропуски (медиана для чисел, MISSING для категорий), масштабирует числовые признаки (min-max), кодирует категориальные (one-hot). Столбец отклика (target_name_) НЕ попадает в матрицу.
