Detailed Description

Общая часть для моделей kNN (регрессор и классификатор).

Содержит: метрику, k, способ взвешивания, ссылку на обучающую выборку, метод fit и метод поиска соседей. Метод predict не реализован — он остаётся наследникам (KnnRegressor, KnnClassifier).

Модель не копирует обучающие данные: хранит указатель на матрицу и span на отклики. Данные должны жить дольше модели.
